# learnings/

One dated file per session or investigation, written when something was
learned the expensive way.

These are not design docs — `stories/` holds those, and stories go stale
once their phases ship. A learning is what survives: a thing that was
believed, a thing that was measured, and what to do about it next time.
Wrong predictions are worth recording precisely because they were
confident.
